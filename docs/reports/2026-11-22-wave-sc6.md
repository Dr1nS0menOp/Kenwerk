# Report: wave SC6, Your account (spec 084)

## What was asked

Rebuild Your account as blueprint 03 arranges it (ADR-045, ADR-051), per the steps of spec 084, on top of the frame of SC1 and the shared settings pieces of SC4 and SC5, all on `main`. The rules of the product owner applied: the app and the API come first together, every feature is reachable through the API, and until 1.0 the API may change radically. Wave MC2, built at the same time, rebuilds the personal token screen, so this wave only places Tokens in the new frame.

## Through the API

Spec 084, "Through the API", lists for every section the routes that read and change it, with the rule each enforces. No route was missing for what this wave shows, and none was added or changed. The sign-in, the sessions and the tokens stay session only on purpose.

## Decided on the product owner's behalf (may be overruled)

D22 to D29 in the spec, dated 2026-11-22: Revoke all tokens waits for MC2 (D22); the body of Tokens is MC2's (D23); the column is the reading column, without a new token (D24); no account menu while a second factor is required (D25); saves speak through the shared message (D26); guide links go to the documents that exist (D27); End all other sessions only while another session exists (D28); Recent logins read the user agent too (D29).

## Gates
