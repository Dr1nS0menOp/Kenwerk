## 3. What was built

- **Server.** A small package `internal/address` builds `/spaces/<key>` and `/spaces/<key>/pages/<id>` and reads both forms of a page address. `document.Normalize` stores every internal page address as `/pages/<id>` with what followed (links, image links, spotlight buttons); `LinkedPages` and the HTML export read both forms. `spaces` holds the answer (`access.go`: `AnswerFor`, `Refusal`, `SetAccessAnswer`, the start answer of a new or personal space), `GetByKey` answers what the space chose, and `Get` shows the setting to its administrators. `sharing.Refusal` decides the answer for a page (rules 21 and 26) and the handler only writes it; `whoToAsk` asks space owners first for a request to view, and a request to view takes turns per person under the cap of 20. `pages.Get` and link facts give `space_key` and `address`, from the query each already runs; notifications carry `address`, which mail uses; `page.url` is the page's address. `apperr` gained the kind for 429.
- **Migration 0076** (expand): `spaces.access_answer` with its check, filled from the feature `access_requests`, default `no_access_ask` afterwards; `space_key_claims` with two triggers that claim and let go of keys.
- **Release rewrite.** `spaceRef` carries the old keys of the draft space, read once per run; addresses of both forms lose their key, old keys become the published key, and the link map keeps them.
- **Client.** `web/src/addresses.ts` builds and reads every page address; about a hundred hand-built addresses in `web/src` now go through `pagePath`, and a lint rule refuses new ones. The router takes both forms; `SpaceHome` shows the home page at the space's address; `SpaceShell` replaces the address with the canonical one once the page is allowed, and space screens reached by an old key show the current one. `components/no-access.tsx` is the no-access screen; the setting is the entry `no-access` of SC5's registry (`views/space-sections.ts`), in the Access group after Permissions, drawn with SC5's `ChoiceTiles`, which gained a `disabled` for the draft space of a pair; it applies at once and says so, and the jump field finds it by the old name Requests for access. Features lost its switch. Copy link everywhere copies the canonical address.
